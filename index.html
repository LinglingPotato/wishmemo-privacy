Privacy Policy — WishMemo for Steam Effective: 4 November 2026. Last updated: 6 November 2026. Applies to WishMemo for Steam 1.0.7 for Microsoft Edge / Chromium browsers and for Firefox. WishMemo is an independent browser extension. It is not affiliated with Valve Corporation or Steam. Summary WishMemo stores notes that you type on your device, in your browser profile. It does not operate a WishMemo server and does not send your notes to the developer over the internet. It does not call the Steam Web API. This policy describes what stays on your device and what the extension can read on Steam store pages. It is not a claim of “zero data” or absolute security: you choose what to write, and exported backups are ordinary files. Notes saved in Edge, Chrome, and Firefox are not shared automatically. Each browser profile has its own copy. Information stored on your device If you write a note, WishMemo saves it in the browser’s extension local storage (chrome.storage.local on Chromium; browser.storage.local / the same storage API on Firefox): Steam App ID, from the store URL path (for example /app/730/) Game title text copied from the page at save time Your note text (up to 4000 characters) Local timestamps and an internal revision number for two-window edits These values do not leave your profile unless you export JSON or copy text with the conflict “copy draft” button. WishMemo does not ask for your Steam account, email, payment details, or precise location. Information read from web pages A content script runs only on https://store.steampowered.com/*. On a game page it may read the URL (App ID) and the visible or Open Graph title. It does not use Steam login cookies to call Steam APIs. It does not run on steamcommunity.com, the Steam desktop client, or unrelated sites. Network The extension does not include analytics, advertising, crash reporting, or a WishMemo backend. Opening a game from the popup navigates to Steam’s store. There is no cloud sync. Import, export, and clipboard Export downloads a JSON file to your computer. Import reads a file you choose and writes notes locally. Everyday saves use a background write queue. Import still stays on-device. On Firefox, choosing Import from the small toolbar popup opens WishMemo in a tab so the system file picker is not interrupted if that popup closes. Copy local draft may place text on the clipboard after you click. Permissions WishMemo requests the storage permission only. Steam store URLs are content-script matches so the panel can appear on game pages. That is not access to your full browsing history. The Firefox package declares that it does not collect data (data_collection_permissions.required: ["none"]). Your controls Edit notes on the game page or in the popup. Delete a note with the clear/delete action (confirmation required). Empty autosave does not delete. Uninstalling typically removes that profile’s extension local storage. Loading the extension from a new unpacked folder may create a new extension ID on Chromium; Firefox uses a fixed add-on ID. Export JSON before switching install paths or browsers. Children WishMemo is not directed at children under 13 and does not knowingly collect children’s information. Changes If storage or network behavior changes, this policy should be updated and the last-updated date changed. This policy page If you are reading this on GitHub Pages, the page is a static file. WishMemo does not run analytics on it. GitHub may process visitor IP addresses and logs under GitHub’s own privacy policy. Contact Use the support email published on the Microsoft Edge Add-ons listing, the Chrome Web Store listing, or the Firefox Add-ons (AMO) listing. Do not contact Valve or Steam support about WishMemo.
